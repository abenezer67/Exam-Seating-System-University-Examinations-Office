Exam Seating Arrangement System

A small system for registering students, defining exam rooms, and generating a randomized seating arrangement for exam day. Use the tabs above to move between sections.

01

Register Students

Add each student's ID, name, and department under the Students tab.

02

Add Exam Rooms

Define each room and its seat capacity under the Rooms tab.

03

Generate Seating

Run the allocation and review the seating chart under the Seating tab.
